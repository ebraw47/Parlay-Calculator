# Parlay Calculator

Free Parlay Calculator for [parlaycalculator.app](https://parlaycalculator.app) — add legs in American, decimal, or fractional odds and see combined odds, total payout, profit, and implied probability instantly.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
